## Getting Started

First, run the development server:

```bash

# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Lead Backend Setup

The contact form, product consultation enquiry, and agent pre-registration form submit to `POST /api/leads`.

## Product Images

Product carousel images should be placed in `public/products/` with these filenames: `life.png`, `health.png`, `takaful.png`, `family.png`, `retirement.png`, and `education.png`. Corporate Plans and Digital Services intentionally use the built-in light blue gradient fallback.

1. Copy `.env.example` to `.env.local` and fill in the values privately. Never expose the Supabase service role key or Gmail app password in client code or `NEXT_PUBLIC_*` variables.
2. Create a `leads` table in Supabase with these columns:

```sql
create table public.leads (
	id bigint generated by default as identity primary key,
	type text not null,
	name text not null,
	phone text not null,
	email text,
	city text,
	age text,
	plan text,
	education text,
	experience text,
	best_time text,
	family_members text,
	message text,
	consent boolean not null default false,
	created_at timestamptz not null default now()
);
```

3. Set `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_URL`, and `SUPABASE_SERVICE_ROLE_KEY` from the Supabase project settings. The public URL and anon key are used by browser-side form fallbacks; the service role key stays server-only.
4. Set `GMAIL_USER`, `GMAIL_APP_PASSWORD`, and `OWNER_EMAIL`. The Gmail account must use an app password for SMTP. Plan applications use the same SMTP settings for the `New Plan Order: [Plan Name]` notification.
5. Set `TELEGRAM_BOT_TOKEN` and `TELEGRAM_CHAT_ID` if Telegram notifications are required.
6. Create the plan application table in Supabase:

```sql
create table public.plan_applications (
	id bigint generated by default as identity primary key,
	plan_name text not null,
	full_name text not null,
	phone text not null,
	cnic_or_age text,
	consent boolean not null default false,
	created_at timestamptz not null default now()
);
```

7. Start the app with `npm run dev` and test the forms. Leads and plan applications are saved before their email notifications are sent; notification failures are logged server-side without exposing details to visitors.

The API accepts `contact`, `plan_enquiry`, and `agent_prereg` lead types, applies server-side validation, silently ignores filled honeypot submissions, and limits each IP to five requests per ten minutes.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
